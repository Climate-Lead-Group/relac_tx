# scripts/figures/report — report figures (Entregable 2)

21 static report figures (`fig_*.py`) plus their master `run_figures.py`. All read the combined CSV
through `figures.common.report_style` / `dashboard_config` (the same oracle as the dashboard) and
default to `report_style.CORE_SCENARIOS` (BAC+ISR). See `scripts/figures/README.md`.

## How to run

```bash
python scripts/figures/report/run_figures.py                 # all figures per run_figures.yaml
python scripts/figures/report/run_figures.py --only fig_x fig_y
python scripts/figures/report/fig_x.py [--years ...] [--scenarios BAC ISR] [--out base]
```

## Gotchas

- `_tmp.py` scripts are experiments, not the official figures: they are present as keys in
  `run_figures.yaml` but set to `false` (checked against the YAML on 2026-09-28), so `run_figures.py`
  skips them unless called with `--only`.
- Every `fig_*.py`'s `main()` is intentionally undocumented — it is exempt in
  `scripts/tests/check_docs.py` (`EXEMPT_FUNCS` inside `FIG_GLOB` files); document the module
  docstring instead.
- The `_ens_tmp` figures value ENS at a VOLL of 1,750 USD/MWh fixed by hand for a specific run
  (2026-09-01); this is **not** the 1,500 USD/MWh VOLL used by dashboard chart_14/chart_15.
